# Support

- **Questions about the code or how something was built:** open an issue with the **Task**
  template.
- **Bugs:** open an issue with the **Fix** template.
- **Security problems:** see [SECURITY.md](SECURITY.md).
- **Your account on the site:** your profile page lets you change your name or delete the
  account.
- **A post, comment or member that breaks the rules:** contact the maintainer through
  [alxpro.com](https://alxpro.com). Report tools on the site itself are planned in #26.
- **Work enquiries:** [alxpro.com](https://alxpro.com).
